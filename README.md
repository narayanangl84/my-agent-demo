# Project Documentation Agent

## Overview

This repository contains a **Documentation Agent** built with LangChain, LangGraph, and Groq. The agent is designed to automate the creation, maintenance, and updating of project documentation such as README files, API guides, and other relevant materials. It works alongside specialized sub‑agents for release notes, issue management, and code review, orchestrated by a central coordinator agent.

## Features

- **Automated README generation** – Write and update the main project README with clear, concise information.
- **API documentation** – Generate detailed API reference guides for the project's modules.
- **Sub‑agent delegation** – Uses dedicated sub‑agents for documentation, release notes, issue handling, and code review.
- **Tool‑driven workflow** – Leverages LangChain tools to read files, search code, and create or modify documentation.
- **Easy extensibility** – Add new documentation tasks or integrate with other CI/CD pipelines.

## Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your‑org/documentation‑agent.git
   cd documentation‑agent
   ```
2. **Create a virtual environment** (optional but recommended)
   ```bash
   python -m venv .venv
   source .venv/bin/activate   # On Windows: .venv\Scripts\activate
   ```
3. **Install dependencies**
   ```bash
   pip install .
   ```
4. **Set up environment variables**
   Copy `sample.env` to `.env` and fill in the required keys (e.g., `GROQ_API_KEY`).
   ```bash
   cp sample.env .env
   ```

## Quick Start

Run the coordinator agent to create documentation and open a pull request:

```bash
python -m src.workflow.main
```

The agent will:
1. Invoke the **documentation sub‑agent** to generate a comprehensive README and API guide.
2. Commit the new files to a feature branch.
3. (If integrated with CI) Open a pull request for review.

## Sub‑Agents Overview

| Sub‑Agent | Responsibility | Tools Used |
|-----------|----------------|-----------|
| `documentation_agent` | Write and update README, API docs, and other documentation. | File read/write, code search |
| `release_notes_agent` | Generate release notes from PRs, commits, and issues. | GitHub API, changelog parsing |
| `issue_agent` | Search, retrieve, and comment on GitHub issues. | GitHub Issue API |
| `code_review_agent` | Review pull requests and provide feedback. | GitHub PR API, file diff tools |
